Balance-Based Dividend Settings
Profit distribution based on balance usage (not shares)

When enabled, profit is distributed based on balance used in purchases. Only shareholders whose balance was used get profit.

{% if enable_balance_dividend %}✅ Enabled{% else %}⛔ Disabled{% endif %}
How it works:
  • Profit distributed based on balance used
  • Only active shareholders with balance usage get profit
  • More balance used = More profit
  • Zero balance = No profit

Share-Based: Based on number of shares held
Balance-Based: Based on balance used in purchases
Both: Admin can choose when creating dividend
